# v1.0 Scope Lock

تاريخ التثبيت: 2026-03-21

## الهدف
هذه النسخة هي نسخة تثبيت وتسليم، وليست نسخة تطوير.

هدف `v1.0`:
- نسخة مستقرة
- قابلة للتسليم
- قابلة للاسترجاع
- واضحة تاريخيًا
- بأقل مخاطرة ممكنة

## ما يدخل v1.0
- bug fixes الواضحة والمعزولة فقط
- تثبيت الاختبارات الحالية
- تجهيزات الإصدار
- التوثيق الأساسي للإصدار
- تحسينات UI الصغيرة التي تم اختبارها بالفعل وتم حفظها في commits مستقلة

## ما لا يدخل v1.0
- features جديدة
- refactor واسع
- أي تغيير غير مكتمل أو محلي فقط
- أي تغيير حساس غير معزول أو غير مجرب
- أي cleanup غير ضروري لا يؤثر على الاستقرار أو التسليم

## المناطق عالية الخطورة
هذه المناطق لا تدخل `v1.0` إلا إذا كان التغيير:
- مفهومًا
- صغيرًا
- معزولًا
- ومجربًا بوضوح

المناطق:
- `lib/data/app_db_transactions.dart`
- `lib/main.dart`
- أي licensing/admin logic
- أي flows مرتبطة بـ `approval / settlement / balances`

## الحالة الحالية بالنسبة لـ v1.0
يدخل ضمن المسار الحالي:
- commits المنفذة والمندمجة سابقًا على `main`
- fixes وUI improvements التي تم فصلها واختبارها
- الاختبارات الصغيرة المستقلة التي تم حفظها بوضوح

يؤجل بعد `v1.0`:
- التغييرات المحلية المؤجلة أو غير النظيفة
- أي ملفات untracked غير داخلة مباشرة في مسار الإصدار
- أي تغييرات متبقية في `app_db_transactions.dart`
- أي تغييرات واسعة في `main.dart`
- أي تغييرات إدارية حساسة غير محسومة

## baseline قبل Release Candidate
الحد الأدنى الإلزامي:
- `flutter analyze`
- `flutter test`

الحد الأدنى اليدوي:
- فتح التطبيق بنجاح
- مراجعة أهم الشاشات الأساسية
- مراجعة العملاء
- مراجعة السجل
- مراجعة تفاصيل العملية
- مراجعة backup/restore إذا كانت ضمن قيمة الإصدار
- مراجعة admin gate / PIN إذا كانت مطلوبة للتشغيل

## قاعدة القرار
إذا ظهر شك في أي تغيير:
- لا يدخل `v1.0`
- يؤجل لما بعد الإصدار

## الخطوة التالية بعد هذا المستند
1. حسم الملفات المحلية المتبقية إلى:
   - يدخل الآن
   - يؤجل بعد `v1.0`
   - يحذف/يتجاهل
2. إعادة الوصول إلى `main` clean state لمسار الإصدار
3. بدء `v1.0.0-rc1` فقط بعد قفل هذا النطاق
