# Release Notes - v1.0.0-rc1

تاريخ الإصدار الداخلي: 2026-03-21

## نوع النسخة
هذه نسخة `Release Candidate` داخلية لـ `v1.0.0`.

الهدف منها:
- التحقق النهائي من الاستقرار
- التحقق من الـ build
- مراجعة smoke يدوية سريعة
- تثبيت حدود الإصدار قبل النسخة النهائية

## ما يدعمه الإصدار
- دورة العمل الأساسية للعمليات مع `pending / approval`
- عرض مرجع العملية بصيغة `ZAxxxxxx`
- البحث في السجل باستخدام مرجع `ZA`
- عرض approval metadata في تفاصيل العملية
- تحسين وضوح partial claim settlements في شاشة العملاء
- دعم الملاحظة الاختيارية في partial claim settlements
- backup / restore
- admin gate / PIN

## أهم ما تم تثبيته قبل RC
- نجاح `flutter analyze`
- نجاح `flutter test`
- قفل نطاق `v1.0` بمستند مستقل
- استبعاد التغييرات المحلية المؤجلة من مسار الإصدار

## ما لا يدخل هذه النسخة
- features جديدة
- refactor واسع
- أي تغييرات غير محسومة في الملفات الحساسة

## Known Limitations
- التغييرات المحلية المؤجلة ليست جزءًا من `v1.0.0-rc1`
- أي عمل متبقٍ في `app_db_transactions.dart` خارج نطاق هذه النسخة
- أي تغييرات واسعة في `main.dart` أو admin control flow ليست ضمن هذه النسخة
