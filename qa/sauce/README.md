# Sauce Labs - Android Smoke (Appium)

## 1) Upload APK to Sauce Storage
- Upload your APK (for example: `app-release.apk`) in Sauce Labs.
- Keep the app reference, usually like:
  - `storage:filename=app-release.apk`
  - or `storage:<app-id>`

## 2) Set environment variables
PowerShell example:

```powershell
$env:SAUCE_USERNAME="YOUR_USERNAME"
$env:SAUCE_ACCESS_KEY="YOUR_ACCESS_KEY"
$env:SAUCE_APP="storage:filename=app-release.apk"
```

Optional:

```powershell
$env:SAUCE_DEVICE_NAME="Android GoogleAPI Emulator"
$env:SAUCE_PLATFORM_VERSION="13.0"
$env:APP_PACKAGE="com.smartcashpro.app"
$env:APP_ACTIVITY="com.smartcashpro.app.MainActivity"
$env:SAUCE_BUILD_NAME="build-2026-02-12"
```

## 3) Install and run

```powershell
cd qa/sauce
npm install
npm run smoke:android
```

## 4) Where to paste capabilities from Sauce UI?
- Open `qa/sauce/smoke_android.js`
- Replace the `capabilities` object with the exact snippet generated by Sauce (if you want 1:1).
- Keep connection fields the same (`hostname`, `user`, `key`, `path`).

## Notes
- This is a launch smoke test (ensures app opens and UI tree is available).
- It saves a screenshot: `sauce_smoke_launch.png`.
- The test marks pass/fail status in Sauce job automatically.
